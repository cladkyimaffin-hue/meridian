## ЦЕЛЬ ДОКУМЕНТА

Цель данного документа описать разработку интеграции между системами «1С:ERP Управление предприятием 2» и «WMS ant LVision» в части обмена данными со стороны 1С.

Данный документ описывает третий этап разработки обмена «Отгрузка товаров со склада».

## ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

Документом «Отгрузки» (в терминологии документа «Интеграция Lvision – 1C»), в 1С:ERP является документ «Складской расходный ордер на товары» (рарусРасходныйОрдерНаТовары), далее рРОнТ.

Документ рРОнТ создается в системе со статусом «Подготовлен» и заполняется автоматически или пользователем. Изменение статуса «Подготовлен» документа рРОнТ пользователем допускается только на статусы «К отбору», «К проверке», «К отгрузке». Статус «Отгружен» устанавливается автоматически на основании данных, полученных из системы LVision. Выгрузка данных рРОнТ из 1С:ERP в базу SQL осуществляется при записи документа в статусе «К отбору».

Если документ рРОнТ в статусе «К отбору» и в него внесены изменения, то при записи, документ должен быть снова выгружен в базу SQL.

Если документ рРОнТ в статусе «Отгружен», то при его перепроведении выгружаются только те данные, которые определены условиями системы LVision.

обратиться к таблицам IFC_ExportOrderHeader и IFC_ExportOrderDetails Базы SQL и обновить данные табличных частей IFC_ExportOrderHeader и IFC_ExportOrderDetails Группы5 (Расходы) обработки РегистрыЕкспортаLVision.

Для получения списка выгруженных документов рарусРасходныйОрдерНаТовары, ожидающих подтверждения отгрузки складом, система должна обратиться к таблице IFC_ImportOrderHeader Группы5 обработки РегистрыЕкспортаLVision и получить список объектов, где значение реквизита IFC_ImportOrderHeader.ОтгруженСкладом = ЛОЖЬ.

Получив список объектов, необходимо выполнить в цикле обход полученной выборки. Для каждой строки выборки необходимо:

обратиться к таблице IFC_ExportOrderHeader Группы5 (Расходы) обработки РегистрыЕкспортаLVision и найти строку, где IFC_ExportOrderHeaderOrderCode = РегистрыИмпортаLVision.IFC_ImportOrderHeaderOrderCode;

из найденной строки таблицы IFC_ExportOrderHeader обработки РегистрыЕкспортаLVision, получить значение ID этой строки;

обратиться к таблице IFC_ExportOrderDetails обработки  РегистрыЕкспортаLVision и найти строку, где РегистрыЕкспортаLVision.IFC_ExportOrderHeader. IFC_ExportOrderHeaderID = РегистрыЕкспортаLVision.IFC_ExportOrderDetails. IFC_ExportOrderDetailsOrderID;

значением атрибута IFC_ExportOrderDetailsQuantity найденной строки заполнить реквизит документа рарусРасходныйОрдерНаТовары.Товары.КоличествоУпаковок в 1С:ERP. Для этого, в списке документов рарусРасходныйОрдерНаТовары системы 1С:ERP найти документ, где значение  рарусРасходныйОрдерНаТовары.СтандартныеРеквизиты.Номер  равен значению ImportOrderHeaderOrderCode табличной части Группы7 обработки РегистрыИмпортаLVision обрабатываемой строки.
