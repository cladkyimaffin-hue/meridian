# 📁 Индекс папки: WmsHost

**Описание:** База знаний по развертыванию, диагностике, обслуживанию и оптимизации хост-серверов WmsHost (гипервизор Hyper-V, Windows Server) и гостевых операционных систем (Ubuntu).

##  Список файлов и их назначение

1. [Утечка памяти.md](./%D0%A3%D1%82%D0%B5%D1%87%D0%BA%D0%B0%20%D0%BF%D0%B0%D0%BC%D1%8F%D1%82%D0%B8.md)
   - **Краткое содержание:** Расследование инцидента с критической загрузкой памяти (>90%) на хосте Hyper-V, зафиксированного в Zabbix.
   - **Ключевые этапы:** 
     - Анализ аномальных процессов (например, `ppbd.exe`).
     - Выявление корневой причины: суммарное статическое выделение RAM виртуальным машинам (`wmsDB`, `wmsWiFi`, `wmsAPP`, `wmsDB_TEST`) превысило физический объем памяти хоста (108 ГБ выделено при 18.5 ГБ физической).
     - Экстренное устранение: остановка новой ВМ `wmsDB_TEST` (8 ГБ), что мгновенно снизило нагрузку (свободная память выросла с 9.04% до 15.31%).
     - Долгосрочное решение: переход на Dynamic Memory и аудит лимитов выделения ресурсов.

2. [Клонирование ВМ.md](./%D0%9A%D0%BB%D0%BE%D0%BD%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5%20%D0%92%D0%9C.md)
   - **Краткое содержание:** Пошаговая инструкция по клонированию виртуальной машины (из `wmsWiFi` в `wmsSQL-Analytics`) на гипервизоре Hyper-V.
   - **Ключевые этапы:** 
     - Копирование диска и создание новой конфигурации ВМ с Virtual Switch Intel I219-LM.
     - Устранение ошибки Secure Boot при первом запуске (отключение для клонированных Ubuntu ВМ).
     - Смена hostname на `wmssql-analytics` через утилиту `hostnamectl` с правкой `/etc/hosts`.
     - Настройка постоянного статического IP-адреса (`192.168.12.202`) через редактирование конфигурации Netplan (`/etc/netplan/50-cloud-init.yaml`) с применением `sudo netplan apply`.
