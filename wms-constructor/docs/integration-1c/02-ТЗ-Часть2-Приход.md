Цель данного документа описать разработку интеграции между системами «1С:ERP Управление предприятием 2» и «WMS ant LVision» в части обмена данными со стороны 1С.

Данный документ описывает второй этап разработки обмена «Приход товаров на склад».

## ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

Документом «Прихода» (в терминологии документа «Интеграция Lvision – 1C»), в 1С:ERP является документ «Складской приходный ордер на товары» (рарусПриходныйОрдерНаТовары), далее рПОнТ.

Документ рПОнТ создается в системе со статусом «К поступлению» и заполняется автоматически или пользователем. При этом, кнопка «Провести» должна быть не активна для пользователя. Изменение статуса «К поступлению» документа рПОнТ пользователем допускается только на статусы «На проверке ОТК», «Согласовано ОТК», «Забраковано ОТК». Иные статусы устанавливаются автоматически на основании данных, полученных из системы LVision. Выгрузка данных рПОнТ из 1С:ERP в базу SQL осуществляется при записи документа в статусе «К поступлению». В базу SQL также выгружаются изменения статусов документа рПОнТ «Согласовано ОТК», «Забраковано ОТК».

Если документ рПОнТ в статусе «К поступлению» и в него внесены изменения, то документ должен быть снова выгружен в базу SQL. Изменения в рПОнТ, если статус документа изменен на любой другой статус не допускаются.

## ПОЛУЧЕНИЕ ДАННЫХ ИЗ СИСТЕМЫ LVISION

## Получение данных о фактической приемке

При запуске регламентного задания KL_ПолучениеДанныхВLVision, система должна:

обратиться к таблицам IFC_ImportReceiptHeader и IFC_ImportReceiptDetails Базы SQL и обновить данные табличных частей IFC_ImportReceiptHeader и IFC_ImportReceiptDetails Группы6 (Приходы) обработки РегистрыИмпортаLVision;

обратиться к таблицам IFC_ExportReceiptHeader и IFC_ExportReceiptDetails Базы SQL и обновить данные табличных частей IFC_ExportReceiptHeader и IFC_ExportReceiptDetails Группы2 (Приходы) обработки РегистрыЕкспортаLVision.

Для получения списка выгруженных документов рарусПриходныйОрдерНаТовары, ожидающих подтверждения приемки складом, система должна обратиться к таблице IFC_ImportReceiptHeader Группы6 обработки РегистрыИмпортаLVision и получить список объектов, где значение реквизита IFC_ImportReceiptHeader.ПринятСкладом = ЛОЖЬ.

Получив список объектов, необходимо выполнить в цикле обход полученной выборки. Для каждой строки выборки необходимо:

обратиться к таблице IFC_ExportReceiptHeader Группы2 (Приходы) обработки РегистрыЕкспортаLVision и найти строку, где IFC_ExportReceiptHeaderReceiptCode = РегистрыИмпортаLVision.IFC_ImportReceiptHeaderReceiptCode;

из найденной строки таблицы IFC_ExportReceiptHeader обработки РегистрыЕкспортаLVision, получить значение ID этой строки;

обратиться к таблице IFC_ExportReceiptDetails обработки  РегистрыЕкспортаLVision и найти строку, где РегистрыЕкспортаLVision.IFC_ExportReceiptHeader. IFC_ExportReceiptHeaderID = РегистрыЕкспортаLVision.IFC_ExportReceiptDetails. IFC_ExportReceiptDetailsReceiptID;

значением атрибута IFC_ExportReceiptDetailsQuantity найденной строки заполнить реквизит документа рарусПриходныйОрдерНаТовары.Товары.КоличествоУпаковок в 1С:ERP. Для этого, в списке документов рарусПриходныйОрдерНаТовары системы 1С:ERP найти документ, где значение  рарусПриходныйОрдерНаТовары.СтандартныеРеквизиты.Номер  равен значению ImportReceiptHeaderReceiptCode табличной части Группы6 обработки РегистрыИмпортаLVision обрабатываемой строки.
