# AI-README.md (домен Monitoring)

## Назначение файла

Объясняет структуру знаний домена `Monitoring/` репозитория `meridian`: порядок поиска и назначение документации. Это не набор команд для безусловного выполнения.

Обязательные правила — в `../AI-INSTRUCTIONS.md` (общий для всех доменов). При противоречии приоритет у него.

---

## 1. Назначение домена

`Monitoring/` документирует мониторинг серверов Meridian: стек Prometheus и Grafana в Docker на сервере `wmssql-analytics`, экспортеры на наблюдаемых серверах (windows_exporter, node_exporter), дашборды, таблицу параметров с порогами и, позже, алерты. Первый наблюдаемый боевой сервер — `wmsDB` (MS SQL Server). Zabbix остаётся для контроля доступности (up/down), Prometheus — для производительности и трендов (подход администратора).

## 2. Главная цель ИИ

Дать быстрый и безопасный ответ о состоянии и устройстве мониторинга. Приоритет — чтение и диагностика без изменений; изменения на серверах только по явному запросу, с проверкой и откатом. Все названия и пояснения на дашбордах — на русском.

## 3. Структура домена

| Папка | Назначение |
|---|---|
| `00_Meta/` | Служебные файлы конвейера: схема, теги, реестр, журнал, конфликты, шаблоны |
| `00_Inbox/` | Необработанные материалы (сырые чаты) до разбора |
| `01_Architecture/` | Стек Prometheus, Grafana, Docker, сеть, хранение (создаётся с первым документом) |
| `02_Exporters/` | windows_exporter, node_exporter, цели, правила файрвола (создаётся с первым документом) |
| `03_MSSQL/` | Метрики SQL Server, читающий логин, пороги (создаётся с первым документом) |
| `04_Dashboards/` | Дашборды Grafana, таблица параметров (создаётся с первым документом) |
| `05_Alerting/` | Alertmanager и уведомления (создаётся с первым документом) |
| `06_Troubleshooting/` | Инциденты и их решения (создаётся с первым документом) |
| `99_Archive/` | Устаревшие документы с `superseded_by` |

Подпапки внутри категорий не используются, пока они не описаны здесь и не согласованы с администратором.

Точный список документов не дублируется в этом файле:

- `00_Meta/registry.csv` — машиночитаемый;
- `INDEX.md` — человекочитаемая навигация, синхронизированная с реестром.

## 4. Приоритет источников

1. Явно сформулированное требование пользователя.
2. Текущая конфигурация и свежий вывод команд.
3. `AI-environment_facts-meridian-monitoring.md` (только `VERIFIED`).
4. Документы этого домена.
5. Официальная документация Prometheus, Grafana, windows_exporter, Microsoft.
6. Общие знания ИИ.

## 5. Как искать ответ

1. Проверить файл фактов среды.
2. Проверить `00_Meta/registry.csv`: нет ли документа на тему.
3. При отсутствии работать по протоколу конвейера, `../AI-INSTRUCTIONS.md`, раздел 8.

## 6. Справочник команд

Файл `COMMANDS.md` с классами `[R]`, `[W]`, `[D]` создаётся вместе с первым документом, содержащим команды, к которым стоит возвращаться.
