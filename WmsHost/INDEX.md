# 📁 Индекс папки: WmsHost

**Описание:** База знаний по диагностике, обслуживанию и оптимизации хост-серверов WmsHost (гипервизор Hyper-V, Windows Server), включая разбор инцидентов и тюнинг ресурсов.

## 📄 Список файлов и их назначение

1. [Утечка памяти.md](./%D0%A3%D1%82%D0%B5%D1%87%D0%BA%D0%B0%20%D0%BF%D0%B0%D0%BC%D1%8F%D1%82%D0%B8.md)
   - **Краткое содержание:** Расследование инцидента с критической загрузкой памяти (>90%) на хосте Hyper-V, зафиксированного в Zabbix.
   - **Ключевые этапы:** 
     - Анализ аномальных процессов (например, `ppbd.exe`).
     - Выявление корневой причины: суммарное статическое выделение RAM виртуальным машинам (`wmsDB`, `wmsWiFi`, `wmsAPP`, `wmsDB_TEST`) превысило физический объем памяти хоста.
     - Экстренное устранение: остановка новой ВМ `wmsDB_TEST` (8 ГБ), что мгновенно снизило нагрузку.
     - Долгосрочное решение: переход на Dynamic Memory и аудит лимитов выделения ресурсов.
