# 📁 Индекс папки: RemoteAPP (Windows Server 2022)

**Описание:** Документация, логи и пошаговые инструкции по развертыванию и настройке служб удаленных рабочих столов (Remote Desktop Services / RemoteApp) на Windows Server 2022.

## 📄 Список файлов и их назначение

1. [Настройка RemoteApp на Windows Server 2022 #1.md](./Настройка%20RemoteApp%20на%20Windows%20Server%202022%20%231.md)
   - **Краткое содержание:** Установка ролей RDS, начальная конфигурация сервера узла сеансов (Session Host) и веб-доступа (Web Access).
   - **Ключевые этапы:** Установка компонентов, базовая настройка коллекции.

2. [Настройка RemoteApp на Windows Server 2022 #2.md](./Настройка%20RemoteApp%20на%20Windows%20Server%202022%20%232.md)
   - **Краткое содержание:** Публикация конкретных приложений, настройка SSL-сертификатов, конфигурация шлюза Remote Desktop Gateway и финальные проверки безопасности.
   - **Ключевые этапы:** Привязка сертификата, правила брандмауэра, тестирование подключения.
