### Общая информация по выгрузке справочников в Базу SQL

Первоначальная выгрузка справочников «Номенклатура», «Поставщики», «Клиенты» осуществляется обработкой «Начальная загрузка справочников».

Список номенклатуры формируется в табличной части страницы «Товары» на основании остатков номенклатуры в системе 1С:ERP. Обновление списка номенклатуры происходит при открытии страницы «Товары» обработки «Начальная загрузка справочников». Выгрузка номенклатуры в базу SQL выполняется при нажатии на кнопку «Передать номенклатуру». В процессе работы с системой, выгрузка номенклатуры будет происходить на основании зарегистрированного к выгрузке документа «Складской приходный ордер на товары». Правила выгрузки номенклатуры на основании документа «Складской приходный ордер на товары» будет описана в Ч.2 «Приходы».

Список поставщиков формируется в табличной части страницы «Поставщики». Обновление списка поставщиков осуществляется нажатием кнопки «Весь список поставщиков». Выгрузка поставщиков в базу SQL выполняется при нажатии на кнопку «Передать поставщиков в LVision». В процессе работы с системой, выгрузка поставщиков будет происходить по факту записи элемента справочника «Партнеры» с признаком «Поставщик». При этом, элемент справочника регистрируется в РС «КЛ_ДанныеВыгрузки» и выгружается в базу SQL при запуске регламентного задания.

Список клиентов формируется в табличной части страницы «Клиенты». Обновление списка поставщиков осуществляется нажатием кнопки «Весь список клиентов». Выгрузка клиентов в базу SQL выполняется при нажатии на кнопку «Передать клиентов в LVision». В процессе работы с системой, выгрузка клиентов будет происходить по факту записи элемента справочника «Партнеры» с признаком «Клиент». При этом, элемент справочника регистрируется в РС «КЛ_ДанныеВыгрузки» и выгружается в базу SQL при запуске регламентного задания.
