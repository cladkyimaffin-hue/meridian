# 📁 Индекс папки: wmsBD

**Описание:** База знаний по администрированию, резервному копированию, восстановлению и лицензированию сервера баз данных Microsoft SQL Server (WMSDB).

## 📄 Список файлов и их назначение

1. [Архивация баз данных SQL Server.md](./%D0%90%D1%80%D1%85%D0%B8%D0%B2%D0%B0%D1%86%D0%B8%D1%8F%20%D0%B1%D0%B0%D0%B7%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85%20SQL%20Server.md)
   - **Краткое содержание:** Настройка автоматического резервного копирования базы `LV_MERIDIAN` на Synology NAS.
   - **Ключевые этапы:** Расчет необходимого места, составление расписания (8 раз в сутки, хранение 7 дней), решение проблемы аутентификации службы MSSQL (ошибка OS 1326) через создание совпадающей учетной записи `sqlbackup`.

2. [Восстановление БД LV_MERIDIAN.md](./%D0%92%D0%BE%D1%81%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%91%D0%94%20LV_MERIDIAN.md)
   - **Краткое содержание:** Регламент проверки целостности резервных копий и процедуры восстановления базы данных.
   - **Ключевые этапы:** Использование `VERIFYONLY`, настройка мониторинга времени последней успешной копии в Zabbix, практика тестового восстановления (drill-restore).

3. [Конфигурация сервера.md](./%D0%9A%D0%BE%D0%BD%D1%84%D0%B8%D0%B3%D1%83%D1%80%D0%B0%D1%86%D0%B8%D1%8F%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D0%B0.md)
   - **Краткое содержание:** Общие параметры и конфигурация сервера баз данных WMSDB.
   - **Ключевые этапы:** Фиксация базовых характеристик окружения (ОС, версия MSSQL, сетевые параметры) для контекста инцидентов и аудита.

4. [Ошибка лицензии.md](./%D0%9E%D1%88%D0%B8%D0%B1%D0%BA%D0%B0%20%D0%BB%D0%B8%D1%86%D0%B5%D0%BD%D0%B7%D0%B8%D0%B8.md)
   - **Краткое содержание:** Анализ статуса активации SQL Server Standard Edition и подготовка отчета для руководства.
   - **Ключевые этапы:** Проверка реестра (ProductID), объяснение природы «общего ключа» (Generic Key) и различий между технической работоспособностью и юридическим лицензированием.

5. [Error 17051 истекла пробная лицензия.md](./Error%2017051%20%D0%B8%D1%81%D1%82%D0%B5%D0%BA%D0%BB%D0%B0%20%D0%BF%D1%80%D0%BE%D0%B1%D0%BD%D0%B0%D1%8F%20%D0%BB%D0%B8%D1%86%D0%B5%D0%BD%D0%B7%D0%B8%D1%8F.md)
   - **Краткое содержание:** Детальный технический протокол восстановления SQL Server 2019 на сервере WMSDB (192.168.12.153).
   - **Ключевые этапы:** Диагностика ошибки 17051 (истечение Evaluation) и критического повреждения файла `sqlservr.exe` (0 байт). Выполнение процедуры Repair через SQL Server Installation Center с использованием ISO-образа, что позволило восстановить бинарные файлы и выполнить Edition Upgrade до Standard Edition.
