# Дашборд «wmsDB: Сервер»: параметры и пороги

## Назначение

Фиксирует состав дашборда «wmsDB: Сервер», пороги триггеров и базовые значения. Это справочник: процедура установки exporter — в `MONITORING-WINDOWS-EXPORTER-WMSDB-2026-001`. Дашборд «wmsDB: MS SQL Server» ещё не создан: его параметры и триггеры обсуждаются отдельно.

### Что делать при отклонении и влияние на WMS

Для каждой панели тексты «что делать» и «влияние на WMS» вшиты в поле `description` (наведение на значок «i»). Кратко: при критических отклонениях WMS замедляется или останавливается (служба SQL, место на дисках, память, процессор, диск); главные требуют внимания в рабочее время; основные — только тренды.

### Ограничения

- Уведомления (Alertmanager, Telegram) не настроены: триггеры сейчас — цвета порогов на панелях. Доставка уведомлений — отдельный этап.
- Службы SQL Server Agent на сервере нет, алерта по ней нет. Резервные копии в планировщике Windows не найдены (вне `\Microsoft` только обновления Edge): контроль бэкапов потребует читающего SQL-логина с правом VIEW SERVER STATE и чтением msdb (на 2026-11-11 право не выдано).

## Источник данных

Панели собраны по метрикам windows_exporter 0.32.0 с `wmsDB`. Запросы проверены в Prometheus 2026-11-11: все возвращают данные (у простаивающего диска задержка пуста: нет операций). Внешний вид панелей в интерфейсе администратором на момент записи не оценён.
